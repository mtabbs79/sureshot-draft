# Sure Shot Supplemental Draft

4-round snake draft from the CBS free-agent pool (pulled Oct 28, 2026). Round 1 order = reverse CBS power rankings.

Deploy on Render: New > Blueprint > pick this repo. Render creates a free web service + free Postgres and asks you for ADMIN_PASSWORD (commissioner password).

Local: `node server.js` (no deps needed locally; picks saved to data/state.json).
